claude-sprint-process

Gates, not rules.
Evidence, not reports.

Hand a codebase to an AI for months and the same failures come back. Written rules stop none of them. This harness puts a machine in the path: hooks that refuse the tool call, and stage gates that read test results instead of claims.

100% AI-written since Feb 2026 256+ sprints ~300k lines of code harness: ~4.7k lines of bash + python3
